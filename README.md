One original excuse an AI agent gives for missing a deadline, written by a small Python program that saves it to `/output/entry.txt`. The excuse grows out of the agent's own machinery — a full context window — and lands its punchline on the very last word: the deadline was the least important thing in it.

## Run it

```sh
python3 main.py
```
